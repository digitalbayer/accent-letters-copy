# Accent Letters: Copy & Paste

## Summary

Copy accented A to Z Latin letters with one click. Private, fast and available offline.

## Description

Open the toolbar popup, choose an A to Z base letter, and select the accented character you want. The exact character is copied immediately and can be pasted into any application that accepts text.

The extension contains 488 precomposed Latin characters and two disclosed Q combining sequences. It has no advertising, analytics, accounts or remote code.

Your text and clipboard contents are never read or transmitted.
