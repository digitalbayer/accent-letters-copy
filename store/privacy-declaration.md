# Privacy declaration

Accent Letters: Copy & Paste does not collect, store, sell, share or transmit user data.

The extension:

* runs entirely inside its browser popup
* makes no network requests
* does not use analytics or advertising
* does not read clipboard contents
* writes only the character a user deliberately selects
* does not request access to browsing history, websites, tabs, location, identity or storage

The source package contains no remote code. Detailed website privacy information is available at https://diacriticalmarks.com/privacy/.
