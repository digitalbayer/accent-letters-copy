# Reviewer notes

## Single purpose

This extension lets users select and copy accented Latin letters organized by their A to Z base letter.

## Testing

1. Open the toolbar popup.
2. Select any base letter from A to Z.
3. Select a character tile.
4. Confirm that the tile and status message report successful copying.
5. Paste into a text field and compare the exact character.

No account or test credentials are required.

## Permissions and data

The extension requests no permissions and no host access. Clipboard writing occurs only in direct response to the user selecting a character. The extension never reads the clipboard and makes no network requests.

All executable source is readable and unminified. There is no generated runtime bundle, remote code, eval or obfuscation.
