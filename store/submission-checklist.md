# Marketplace submission checklist

## Chrome Web Store

* Register and verify the publisher account.
* Upload `dist/chrome/accent-letters-copy-1.0.0.zip`.
* Use the Chrome listing text and store images.
* Declare the single purpose from `reviewer-notes.md`.
* Declare that no user data is collected or transmitted.
* Set the homepage to https://diacriticalmarks.com/accent-letters/.
* Set the support URL to https://diacriticalmarks.com/contact/.
* Submit for review with deferred publishing if a final listing inspection is desired.

## Firefox Add-ons

* Sign in with a Mozilla account.
* Choose a public listing on addons.mozilla.org.
* Upload `dist/firefox/accent-letters-copy-1.0.0.zip`.
* Use the Firefox listing text and reviewer notes.
* Select the appropriate extension license.
* Confirm that the package is readable and unminified, so no separate source archive is needed unless AMO requests one.
* Submit for validation and review.
